# @booking/governance

Versioned governance metadata for the Booking platform.

This package intentionally stores identifiers, editions, applicability metadata, internal controls, mappings, and evidence expectations rather than reproducing copyrighted standards text.

The registry is designed to become a machine-readable input to the future governance/evidence plane described in Issue #6. Changes to standards or controls should be reviewed as policy/configuration changes and remain reconstructable historically once persistent governance services are introduced.
